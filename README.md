## 🚀 Running Locally

No build tools needed — just open the file:

```bash
# Clone the repo
git clone https://github.com/ramesh980514/PersonalSite.git

# Open in browser (double-click or use a local server)
cd PersonalSite
start index.html

# Or with VS Code Live Server extension:
# Right-click index.html → "Open with Live Server"
```
